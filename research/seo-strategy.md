## 1. Where we're playing (and where we're not)

We are a **trust-led, heritage-rooted D2C Ayurvedic brand** selling a focused catalog of
oils, tablets, and churnas. Our SEO must do two jobs at once:

1. **Capture commercial-intent buyers** searching for the exact remedy we make.
2. **Build topical authority + trust** so Google and LLMs cite us as a credible Ayurvedic
   source — without ever making a non-compliant health claim.

### Our product catalog (what we can legitimately rank for)

| Product | Type | Maps to search demand |
|---------|------|----------------------|
| **Flexio Oil** | Joint/muscle pain massage oil (Nirgundi, Mahavishagarbha) | 🟢 joint-pain-oil cluster — researched, KD=0 |
| **AllerGenie** | Ayurveda allergy support tablet | 🟡 allergy cluster — researched, content play |
| **Sports Edge Oil / Junior** | Body massage oil for athletes/kids | ⚪ "sports massage oil", recovery — not yet researched |
| **Vario Oil + Vario tablet** | Varicose vein support | ⚪ "varicose veins treatment" — not yet researched |
| **Uristo + Uristo Choornam** | Urinary tract / UTI wellness | ⚪ "UTI home remedy / burning urination" — not yet researched |
| **Endurio 35+** | Men's health, Shilajit-fortified | ⚪ "shilajit / stamina / men's wellness" — not yet researched |
| **Glycemio Choornam** | Metabolic / diabetes support powder | ⚪ "diabetes ayurvedic / sugar control" — not yet researched |

### Clusters we are deliberately **ignoring** (and why)

- `ayurved-institution` (hospitals, colleges, "ayurved near me", admissions) — these are
  navigational/local searches for institutions, **not buyers of D2C products**. Zero fit.
- `ayurved-generic-branded` (Patanjali, Karma Ayurveda, Baidyanath, etc.) — competitor brand
  terms. We don't outrank them and the traffic wouldn't convert.
- `ayurved-hair-oil` — **we don't sell a hair oil.** Chasing it would be content with no
  product to convert against. (If we ever launch one, revisit.)

> **CMO principle:** every keyword we target must have a product behind it that we can
> honestly recommend. No traffic-for-traffic's-sake content.

## 3. Allergy cluster → AllerGenie (phase 2, content-led)

### The honest read

- **250 keywords, ~5,200 India searches/month** — meaningful demand.
- BUT the intent is **overwhelmingly informational** (`how to cure X allergy`) and the
  **KD is much higher** (skin allergy 23, dust allergy 37, "allergy cure" 62). This is a
  *content-authority* play, not a quick commercial win.
- 🚩 **Compliance landmine.** Searchers literally type *"how to cure allergy permanently."*
  **We must never claim AllerGenie "cures" allergies.** AYUSH/ASCI norms and basic honesty
  forbid it. Our angle is *Ayurvedic support, management, and relief* — framed around
  classical usage (Pratishyaya, Kasa, Peenas), never a cure promise.

## 4. On-page & technical SEO (the foundation under all of it)

We're on **Next.js 14 App Router + WooCommerce** — already a strong SEO base. Make sure:

1. **Structured data (schema.org) — highest priority.**
   - `Product` + `Offer` schema on every product page (price, availability, brand).
   - `AggregateRating` once we have real reviews (never fake them — trust is sacred).
   - `FAQPage` schema on product pages using the Tier-2 questions.
   - `BreadcrumbList` (Breadcrumb component already exists).
   - This is what gets us into **rich results AND LLM citations** — do it everywhere.
2. **Metadata via App Router `generateMetadata`** — unique title + description per product,
   each leading with the primary keyword (e.g. "Ayurvedic Joint Pain Oil").
3. **Core Web Vitals** — hero LCP work is already underway (good). Keep product images
   optimized via `next/image` (already configured for the WooCommerce domain).
4. **India-targeting signals** — `hreflang="en-IN"`, INR pricing in schema, India-based
   trust signals (FSSAI/AYUSH license numbers, India shipping/COD messaging). The
   "best joint pain oil **in india**" keyword shows users want local.
5. **Internal linking** — blog → product, related products → each other
   (`productRelationships.ts` already exists; use it to build a link graph).
6. **XML sitemap + robots** — generate from the product list; submit to Search Console.

## 5. LLM / AI-search visibility (CMO + CDO note)

Indian buyers increasingly ask ChatGPT/Gemini "best ayurvedic oil for knee pain." To be
**citation-ready**:

- Write content with **clear, factual, ingredient-level claims** (scientific names,
  classical Ayurvedic indications) — LLMs cite precise, structured sources.
- Use **FAQ + clean headings + tables** (parseable structure beats prose walls).
- Keep claims **defensible and sourced** — an LLM won't cite "cures everything," but it
  *will* cite "Nirgundi (Vitex Negundo) is traditionally used in Ayurveda for joint comfort."
- Honesty is the moat here, same as everywhere.
